================
Report a bug
================

#. Use **Report a bug** at the bottom of any page. It opens a new issue on `GitHub <https://github.com/PyCalendar/community-insights/issues>`_ with the page and the version filled in. The version is also on the **About** page.
#. Describe what happened, what you expected and the steps to see it.
#. Never paste tokens, cookies or the address of a badge of a private project: the badge address contains its secret token.

Security problems
=================

Do not open a public issue. See :doc:`../security`.
